# Тесты

Тесты написаны на JUnit 5 + Mockito, лежат в [src/test/java](/src/test/java).

Результаты и coverage опубликованы с помощью CI на [GitHub Pages](https://final-coverage.belyaev.work/).

Покрытие строк ~72%. Порог покрытия 70% задан в [pom.xml](/pom.xml) и проверяется автоматически Maven на фазе `test`.

## Что не тестируется

Не тестируется работа с сетью и многопоточность, так как это бы тестировалось интеграционными тестами.
